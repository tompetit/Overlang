# Tab-separated /todos.txt

Scripts that read `/todos.txt` want something easier to split. Change each line to three tab-separated
fields: the id, the word `done` or `open`, and the title, for example `1<TAB>open<TAB>buy milk`. Still one
line per todo in id order, each ending in a newline, still `text/plain`. The HTML page keeps its `[x]` and
`[ ]` marks.

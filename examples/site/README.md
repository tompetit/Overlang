# Overlang home page

The site served by GitHub Pages from `docs/` is generated by this Overlang program.

- `html.ov`: a small front-end framework. A `Node` type (element, text, raw), Elm-style builders
  (`el`, `text`, `attr`, `div`, `p`, `h1`..`h3`, `a`, `ul`, `li`, `pre`, `code`, `section`, `nav`,
  `header`, `footer`, `table`, `tr`, `td`, `th`, `img`, `meta`, `link_el`), `render` to HTML5 with
  escaping, `page` for the document wrapper, components (`code_block`, `card`, `data_table`,
  `comparison`, `nav_bar`), and a `Css` type with `render_css`. `link` is a keyword, hence `link_el`.
- `main.ov`: the page content and the stylesheet. Every number comes from `docs/RESULTS.md` and
  `docs/PLAN.md`; the hero code sample is copied verbatim from `examples/todo/main.ov`.

## Build

```
cargo build --release
examples/site/build.sh      # runs the tests and fuzzing, then writes docs/index.html and docs/site.css
```

There are no modules in v0.1, so both files are passed to `ov` together and share one namespace. The
prelude cannot write files, so the binary prints `index.html` by default and `site.css` when given
the argument `css`, and `build.sh` redirects each into `docs/`. Commit the regenerated files: Pages
serves them as committed.
